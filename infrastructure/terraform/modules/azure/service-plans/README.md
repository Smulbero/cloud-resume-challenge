# Module: azure/service-plans

Creates one or more Azure Service Plans from a map of definitions.

The Resource Group names are generated by prefixing each 'name' property with
`var.resource_name_prefix` (default `sp`) followed by `random_integer` (default length `4`)

## Requirements

No requirements.
