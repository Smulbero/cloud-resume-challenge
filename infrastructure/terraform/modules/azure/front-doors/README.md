# Module: azure/front-doors

Creates one or more of the following Azure Front Door resources from a map of definitions:
- Frontdoor Profile
- Frontdoor Endpoint
- Frontdoor Origin Group
- Frontdoor Origin
- Frontdoor Custom Domain
- Frontdoor Route
- Frontdoor Firewall Policy
- Frontdoor Security Policy

The Frontdoor Profile names are generated by prefixing each 'name' property with
`var.resource_name_prefix` (default `afd`) followed by `random_integer` (default length `4`)

No requirements.
