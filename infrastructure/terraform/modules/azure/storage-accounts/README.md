# Module: azure/storage-accounts

Creates one or more of the following Azure Storage Account resources from a map of definitions:

- Azure Storage Account
- Azure Storage Account Static Website
- Azure Storage Container

The Storage Account names are generated by subfixing each 'name' property with
`random_integer` (default length `4`)

## Requirements

No requirements.
